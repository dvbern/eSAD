# Add a dataset to the HelloData export API

## Arguments

- `<Entity>` = `$entity` (singular, as in the JPA entity, e.g. `Kind`)
- `<path>` = `$path` (plural REST path segment, lowercase ASCII, e.g. `kinder`)

If either is empty, stop and ask for it before changing anything.

## Naming (derive once, use everywhere)

`<Entities>` = `<path>` with the first letter upper-cased (`kinder` → `Kinder`).

| Artifact          | Name                                                        | Model on                                                    |
|-------------------|-------------------------------------------------------------|-------------------------------------------------------------|
| Row DTO           | `json/HelloData<Entity>Json`                                | `HelloDataSchuleJson`, `HelloDataImpfstoffJson`             |
| Envelope DTO      | `json/HelloData<Entities>EnvelopeJson`                      | `HelloDataSchulenEnvelopeJson`, `HelloDataImpfstoffeEnvelopeJson` |
| Repo              | `HelloData<Entity>Repo`                                     | `HelloDataSchuleRepo`, `HelloDataImpfstoffRepo`             |
| QueryDSL          | `Q<Entity>` (generated by `./mvnw compile`, never hand-written) | —                                                        |
| Service methods   | `write<Entities>(OutputStream)`, `write<Entities>AsJson(OutputStream)` | Schulen methods                                  |
| Resource paths    | `/ndjson/<path>`, `/json/<path>`                            | Schulen methods                                             |
| Integration test  | `HelloData<Entities>ResourceITest`                          | `HelloDataImpfstoffeResourceITest`                          |
| Bruno requests    | `0<n>a-export-<path>.bru`, `0<n>b-export-<path>-json.bru`   | `02a-export-schulen.bru`, `02b-export-schulen-json.bru`     |

Rule of thumb: row DTO and repo are **singular**; everything describing the
collection (envelope, paths, service methods, ITest, Bruno) is **plural**.

**Confirm the resolved names with the user before step 1.**

## Context

Feature package `ch.dvbern.oss.hemed.esc.api.features.hellodata`: a machine-to-machine
full-load export. HelloData pulls each dataset once per night as **NDJSON** and as a
**JSON container**, both streamed. The canonical recipe and the reasoning behind every
rule live in
[`HELLO_DATA_README.md`](../../../api/src/main/java/ch/dvbern/oss/hemed/esc/api/features/hellodata/HELLO_DATA_README.md)
("Adding a new dataset" + "Architecture"). **Read it first**; this skill is the checklist
and the pitfalls.

Paths below are relative to `api/src/main/java/.../features/hellodata/` unless noted.
Do not touch the shared writers (`NdjsonWriter`, `JsonEnvelopeWriter`,
`HelloDataExportWriter`) or `json/HelloDataSentinelJson` / `json/HelloDataMetaJson`.

## Checklist (in order)

1. **Row DTO** `json/HelloData<Entity>Json`
   - `@Value @AllArgsConstructor @JaxDTO`; every field `@NotNull @NonNull @Schema(required = true)`.
   - A contract towards HelloData, not a mirror of the entity: export only what analytics
     needs. Never contact details, free text or staff personal data.
   - Raw `UUID` id (not `ID<Entity>`) with `@IgnoreForIdClassTest`; the wire must not couple
     to the internal ID wrapper.

2. **Envelope DTO** `json/HelloData<Entities>EnvelopeJson`
   - `List<HelloData<Entity>Json> data` and `HelloDataMetaJson meta` annotated
     `@JsonProperty(HelloDataSentinelJson.META_KEY)`, `_meta` last.
   - Describes the wire format for OpenAPI only; never serialised into a response (would
     buffer every row).

3. **Repo** `HelloData<Entity>Repo extends ReadOnlyRepo` (not `BaseRepo`)
   - `@Repository @RequiredArgsConstructor`, one `streamAll()` returning a cursor-backed
     `Stream<HelloData<Entity>Json>`:
     `db.select(Projections.constructor(...))` over `Q<Entity>`,
     `.orderBy(<entity>.id.asc())`, `.setHint(HibernateHints.HINT_FETCH_SIZE, 500)`, `.stream()`.
   - The stream holds an open cursor; the caller closes it inside the transaction.
   - If multi-valued associations or roles need to be combined into a string column, aggregate directly in the query projection
        (e.g. `Expressions.stringTemplate("coalesce(listagg(cast({0} as string), ',') within group (order by {0}), '')", ...)`
        with `.groupBy(...)` as in `HelloDataBenutzerRepo`) instead of loading entities into memory.
   
4. **Service** `HelloDataExportService`
   - Inject the repo as a `final` field.
   - `write<Entities>(os)` → `write("<path>", repo::streamAll, ndjsonWriter, os)`;
     `write<Entities>AsJson(os)` → same with `jsonEnvelopeWriter`.
   - Carry over `@Bulkhead(1)`, `@Timed(...)` and **`@TransactionConfiguration(timeout =
     EXPORT_TRANSACTION_TIMEOUT_SECONDS, timeoutFromConfigProperty =
     TRANSACTION_TIMEOUT_PROPERTY)`**. Without it Narayana's 60 s default rolls the export
     back mid-stream, silently: the response ends without `_meta`.
   - Do not inline the loop: sentinel, flush cadence, audit and abort stay in the private
     `write(...)`.

5. **Resource** `HelloDataResource`
   - `@GET /ndjson/<path>` → `ndjson(service::write<Entities>)`
   - `@GET /json/<path>` → `streamed(service::write<Entities>AsJson, JsonEnvelopeWriter.MEDIA_TYPE)`
   - Copy the annotations from the Schulen methods: `@Produces`, `@Blocking`,
     `@RateLimit(HELLODATA_EXPORT_LIMIT)`,
     `@RolesAllowed({ BerechtigungName.HELLODATA_EXPORT_LESEN })`, `@APIResponse`/`@Content` with
     - NDJSON: `@Schema(oneOf = { HelloData<Entity>Json.class, HelloDataSentinelJson.class })`
     - JSON: `@Schema(implementation = HelloData<Entities>EnvelopeJson.class)`
   - Add a per-dataset NDJSON description constant.

6. **Docs** `HELLO_DATA_README.md`
   - Endpoint table (both paths), a `HelloData<Entity>Json` contract table (field, type,
     required, notes), datasets line, architecture diagram (new repo under the service).
   - If the entity has no tenant column, say so in the contract section (see Pitfalls).

7. **Regenerate the full OpenAPI spec**: `./mvnw compile quarkus:build`
   - `compile` is mandatory; `quarkus:build` alone augments stale `target/classes` and
     silently writes a spec without the change. Output: `api/openapi-schema/openapi.yaml`.

8. **Regenerate the reduced contract**: run `HelloDataOpenApiContractTest` **twice**
   - Run 1 fails by design (rewrites `api/openapi-schema/hellodata-openapi.yaml`); run 2 is green.
   - Review `git diff hellodata-openapi.yaml`; HelloData generates their ingestion models from it.

9. **Integration test** `src/test/java/.../features/hellodata/HelloData<Entities>ResourceITest`
   (`@QuarkusTest`)
   - `setUp()`: tenant `TenantEnum.BE` via the injected `TenantProducer`; seed rows with the
     entity's `testutil.builder`.
   - Assert: the seeded row appears with each field carrying its own column's value; last
     line is a `_meta` sentinel with `status = complete` and `rowCount` = data rows; NDJSON and
     JSON carry the same rows; the JSON body matches `HelloData<Entities>EnvelopeJson`
     field-for-field; tenant-BE, role and no-auth guards behave.

10. **Bruno requests** in `api/bruno/hellodata/`
    - `0<n>a-export-<path>.bru`: `Accept: application/x-ndjson`, `/ndjson/<path>`
    - `0<n>b-export-<path>-json.bru`: `Accept: application/json`, `/json/<path>`
    - `0<n>` and the `seq` in `meta` continue past the last existing request
      (Impfstoffe = `03a`/`03b`, `seq` 4/5).
    - Reuse `{{baseUrl}}`, `{{accessToken}}` and the `tests` blocks (`_meta` + `rowCount`);
      only `docs` and the tenant note change.

## Pitfalls

- **Singular vs. plural.** `HelloData<Entity>Json` vs. `HelloData<Entities>EnvelopeJson`
  differ by more than a suffix (`Kind`/`Kinder`, `Anlass`/`Anlaesse`); check both in review.
- **Tenant gate lives in the service** (`HelloDataExportService.requireAllowedTenant(...)`),
  export is BE-only. An entity without a tenant column (like `Impfstoff`) exports all rows;
  the BE gate still applies. Document it in the README and the Bruno `docs` block.
- **Regeneration order** 7 → 8. A skipped `compile` or a single contract-test run leaves a
  stale `hellodata-openapi.yaml` that passes locally but ships the wrong contract.

## Verify

- `./mvnw compile quarkus:build` succeeds.
- `HelloDataOpenApiContractTest` green on the second run; `git diff hellodata-openapi.yaml`
  shows exactly two new paths and two new schemas.
- `HelloData<Entities>ResourceITest` passes (AssertJ).
- Prefer running tests via the IntelliJ MCP. From a non-hooked shell set
  `export JAVA_HOME="$HOME/.version-fox/sdks/java"` before `./mvnw`.
